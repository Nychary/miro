# Конструктор уроков для Miro

Панель внутри доски Miro, которая собирает готовый урок по физике или английскому:
теорию, формулы, задачи, интерактивные задания и отдельный фрейм с ответами
для преподавателя.

Сейчас готовы каркас приложения и движок раскладки — урок рисуется из
заготовленного описания. Генерация содержания нейросетью подключается следующим
этапом; для рендерера ничего не изменится, потому что он уже принимает ровно тот
формат, который будет выдавать модель.

## Как устроено

```
панель в Miro  ──►  описание урока (JSON)  ──►  движок раскладки  ──►  Web SDK
                     что именно на уроке        где что лежит        объекты на доске
```

Ключевое разделение: **описание урока не содержит координат**. В нём есть
«теория из четырёх тезисов» и «шесть задач», но нет ни одного числа про
пиксели. Всё оформление живёт в `src/render`. Поэтому нейросети не придётся
думать про вёрстку — она отвечает только за содержание.

| Файл | Зачем |
|---|---|
| [src/lesson/schema.ts](src/lesson/schema.ts) | Модель урока. Центральный контракт проекта |
| [src/lesson/samples.ts](src/lesson/samples.ts) | Два настоящих урока — образец для отладки вёрстки |
| [src/render/theme.ts](src/render/theme.ts) | Все размеры, отступы и цвета |
| [src/render/canvas.ts](src/render/canvas.ts) | Прослойка над Web SDK: курсор, габариты, примитивы |
| [src/render/composition.ts](src/render/composition.ts) | Секции, карточки, сетки, колонки |
| [src/render/blocks.ts](src/render/blocks.ts) | По рендереру на каждый тип блока |
| [src/render/renderLesson.ts](src/render/renderLesson.ts) | Сборка урока и упаковка во фрейм |
| [src/render/metadata.ts](src/render/metadata.ts) | Разметка для будущей автопроверки заданий |

Две особенности Miro, которые определили устройство рендерера:

1. **Высоту текста нельзя посчитать заранее** — её решает сам Miro, когда
   переносит строки. Поэтому текст сначала создаётся, потом у него читается
   фактическая высота, и только после этого он ставится на место.
2. **Объекты не прикрепляются к фрейму сами.** Фрейм создаётся последним, уже
   по фактическим габаритам содержимого, а объекты складываются в него явно.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Дальше приложение нужно один раз зарегистрировать в Miro:

1. Завести Developer team на [developers.miro.com](https://developers.miro.com)
   и создать в ней приложение.
2. В настройках приложения вставить содержимое [miro-manifest.yml](miro-manifest.yml).
3. Установить приложение в свою команду.
4. Открыть любую доску, нажать «+» на левой панели и выбрать «Конструктор уроков».
5. В открывшейся панели нажать одну из кнопок — на доске появится урок.

Пока `sdkUri` указывает на `http://localhost:3000/`, приложение работает только
при запущенном `npm run dev`.
